## Lean 程式碼（`Answer.lean`）

```lean
import Mathlib

open Finset

/-- 定理：對每個正整數 n，1 + 3 + 5 + ⋯ + (2n − 1) = n²。
左邊寫成 ∑_{i=1}^{n} (2i − 1)。 -/
theorem sum_odd (n : ℕ) (hn : 1 ≤ n) :
    ∑ i ∈ Icc 1 n, (2 * i - 1) = n ^ 2 := by
  -- 從 n = 1 開始的數學歸納法
  induction n, hn using Nat.le_induction with
  | base =>
    -- n = 1：左邊是 1，右邊是 1
    simp
  | succ n hn ih =>
    -- 歸納步驟：把第 n+1 項 2(n+1) − 1 拆出來，再用歸納假設
    rw [sum_Icc_succ_top (by omega), ih]
    -- n² + (2(n+1) − 1) = n² + 2n + 1 = (n+1)²
    have h : 2 * (n + 1) - 1 = 2 * n + 1 := by omega
    rw [h]
    ring
```

證明的結構和課本一樣：
- **基底 `base`**：n = 1 時，左右兩邊都是 1。
- **歸納步驟 `succ`**：先用 `sum_Icc_succ_top` 把最後一項 2(n+1) − 1 拆出來，再代入歸納假設 `ih`（前 n 項的和是 n²），整理成 n² + 2n + 1 = (n+1)²。

## Lean 陳述和課本是否完全一致？

在數學意義上兩者等價，但寫法有三處不同：

1. **「正整數 n」**：Lean 寫成自然數 `n : ℕ`（包含 0）加上假設 `1 ≤ n`。兩者是同一組數 {1, 2, 3, …}。歸納法用 `Nat.le_induction`，從 n = 1 開始，和課本的基底一樣。
2. **「1 + 3 + ⋯ + (2n − 1)」**：「⋯」不是正式記號，我把它理解成 ∑_{i=1}^{n} (2i − 1)，也就是 `∑ i ∈ Icc 1 n, (2 * i - 1)`。這是這個式子的標準讀法，也剛好去掉了一個歧義：n = 1 時，課本的寫法字面上像是「1 + 3 + ⋯」，但真正的意思是只有一項 1。
3. **減法**：在 ℕ 裡，`a - b` 是截斷減法（a < b 時結果是 0）。不過求和範圍裡 i ≥ 1，所以 2i − 1 ≥ 1，截斷不會發生，和一般整數減法的結果一樣。證明中的 `2 * (n + 1) - 1 = 2 * n + 1` 也是在這個前提下由 `omega` 驗證的。

另一種常見寫法是 `∑ i ∈ range n, (2 * i + 1) = n ^ 2`（i 從 0 跑到 n−1），完全不用減法，而且 n = 0 時也成立。但它的形式離課本比較遠，所以我選了現在這個比較貼近課本的版本。
