## 本章目標

1. 把課本上「展開、移項、平方非負」的推導，對應到 Lean 的引理與 tactic。
2. 依目標的樣子選工具：`ring`、`linarith`、`positivity`、`simp`、`exact?`。
3. AI 建議一個引理名稱或 tactic 時，知道如何驗證它存在、而且說的就是你要的事。

## mathlib：先找再證

mathlib 是 Lean 社群共同維護的數學函式庫，涵蓋代數、分析、拓撲、數論、線性代數等大量內容。課程專案已經把它設為依賴，檔案開頭寫 `import Mathlib` 就能使用其中的定義與定理。

形式化數學時，大部分時間不是在發明新證明，而是在**找到正確的既有引理並把它接上**。紙上一句「因為平方非負」，在 Lean 中就是找到 mathlib 的 `sq_nonneg`，並確認它說的正是你要的事。

## 一個微積分常用的不等式

課本上的證明：對任意實數 $x, y$，$2xy \le x^2 + y^2$。因為 $(x-y)^2 \ge 0$，展開得 $x^2 - 2xy + y^2 \ge 0$，移項即得。在 Lean 中，這個證明只有一行：

<PaperVsLean file="Course/University.lean" region="uni-two-xy" rows={["2", "3"]}>
  <Fragment slot="p1">**定理**：對任意實數 $x, y$，$2xy \le x^2 + y^2$。</Fragment>
  <Fragment slot="p2">因為 $(x - y)^2 \ge 0$，展開、移項即得。證畢。</Fragment>
</PaperVsLean>

`sq_nonneg (x - y)` 是 mathlib 中「$(x-y)^2 \ge 0$」的證據，也就是紙上那句「因為」。`nlinarith` 拿到這個提示之後，自己完成展開與移項。

<Term term="自動化 tactic" short="一個 tactic 自己搜尋、計算出整段推導，不需要你一步步寫。">

`ring`、`linarith`、`nlinarith`、`positivity`、`simp` 都屬於這一類。它們各有擅長的目標形狀；遇到不擅長的目標就會失敗，並不會「猜」出證明。`nlinarith [提示]` 的方括號裡放的是你提供的額外事實，它會把這些事實與假設相乘、相加，嘗試湊出目標。

</Term>

一行很方便，但你看不到中間發生了什麼。把同一個證明照紙上的步驟拆開，每一行都對得上：

<PaperVsLean file="Course/ExtraA.lean" region="extra-two-xy-steps" rows={["2", "3", "4", "5", "6"]} title="同一個證明，拆成紙上的每一步">
  <Fragment slot="p1">**定理**：對任意實數 $x, y$，$2xy \le x^2 + y^2$。</Fragment>
  <Fragment slot="p2">平方非負：$(x - y)^2 \ge 0$。</Fragment>
  <Fragment slot="p3">展開：$(x - y)^2 = x^2 - 2xy + y^2$。這是代數恆等式。</Fragment>
  <Fragment slot="p4">代入，得到 $x^2 - 2xy + y^2 \ge 0$。</Fragment>
  <Fragment slot="p5">移項，得 $2xy \le x^2 + y^2$。證畢。</Fragment>
</PaperVsLean>

這裡用了三個不同的工具，各做一件事：

- `sq_nonneg` 是一條 **mathlib 引理**，提供「平方非負」這個事實。
- `ring` 證明**代數恆等式**：展開 $(x-y)^2$ 不需要任何假設，只靠交換環的運算規則。
- `linarith` 處理**線性不等式**：手上有 `h : 0 ≤ x ^ 2 - 2 * x * y + y ^ 2`，目標只是它移項後的樣子。

`rw [expand] at h` 則是「代入」：把 `h` 裡的 `(x - y) ^ 2` 換成展開式。執行後，Infoview 中的 `h` 變成 `0 ≤ x ^ 2 - 2 * x * y + y ^ 2`。

請自己試試：把 `ring` 換成 `linarith`，或把 `linarith` 換成 `ring`，看哪些仍成功、哪些失敗。工具的能力有重疊，例如本課程固定版本中，第一個恆等式用 `linarith` 也能過，因為正規化之後兩邊相同。但 `ring` 更直接表達了「這是交換環恆等式」的理由。不能只看式子裡有沒有乘號，就斷定哪個工具能處理。

<details>
<summary>補充：六個常用工具的能力與限制</summary>

| Tactic | 主要用途 | 使用時要注意 |
| --- | --- | --- |
| `simp` | 用一大批標記為簡化規則的等式反覆改寫，例如消掉 `x + 0`、展開空和 | 不保證停在你想要的形式；不會自己找出非顯然的論證 |
| `ring` | 交換環中的恆等式，例如 `(a + b) ^ 2 = a ^ 2 + 2 * a * b + b ^ 2` | 不推理不等式，不使用假設，也不會展開有限和 |
| `linarith` | 從線性等式與不等式推出目標 | 會先正規化多項式，所以也能處理某些含乘積的式子；不能代替一般非線性推理 |
| `nlinarith` | `linarith` 的延伸，會嘗試把假設兩兩相乘，能處理部分非線性情況 | 可能很慢或失敗；常需要你提供提示項，例如 `sq_nonneg (x - y)` |
| `positivity` | 依式子結構證明 `0 < …` 或 `0 ≤ …`，例如平方、絕對值、正常數的組合 | 能使用適當的局部正性假設；不會解決任意不等式 |
| `norm_num` | 具體數字的計算與比較，例如 `(2 : ℝ) / 4 = 1 / 2` | 不處理一般含變數的代數 |

</details>

### `ring` 不看假設

一個常見的誤會：「用 `ring` 就能從 `h : x = 2` 證明 `x ^ 2 = 4`。」這不對。`ring` 只證明**對所有 x 都成立**的恆等式，不使用假設，而 $x^2 = 4$ 不是恆等式。正確做法是先用 `rw [h]` 把 x 換成 2，再讓 `norm_num` 計算：

### `simp` 的使用習慣

`simp` 很強，也容易讓證明變脆弱：mathlib 更新後，`simp` 的規則集可能改變，原本能過的證明可能不再通過。用 `simp` 收尾（直接關閉目標）通常沒問題；在證明中途使用、之後還要接其他 tactic 時，先寫 `simp?`，它會告訴你實際用到哪些規則，再換成明確的 `simp only [...]`。

## 找引理：命名慣例、`#check` 與 `exact?`

mathlib 的引理名稱大致描述它的結論，由符號的英文名組成，順序和式子中出現的順序相近：

- `mul_comm`：乘法交換律，`a * b = b * a`。
- `add_pos`：兩個正數相加為正。
- `sq_nonneg`：平方非負，`0 ≤ a ^ 2`。
- `Finset.sum_range_succ`：range (n + 1) 上的和，等於拆出最後一項。
- `le_of_lt` 這類名字中，`_of_` 後面接的是**假設**，前面是**結論**；`_iff` 表示雙向。

舉例：在 $\mathbb{R}$ 上，「若 $0 \le a$ 且 $0 \le b$，則 $0 \le a + b$」叫什麼？結論是「加法的非負」，猜 `add_nonneg`。猜到之後，**一定要 `#check`**，再實際用一次：

<LeanCode file="Course/ExtraA.lean" region="extra-find-lemma" />

`#check add_nonneg` 會顯示它在一般的有序結構上成立，`ℝ` 是其中一個特例。讀陳述時要確認三件事：變數的型別（`ℕ`、`ℤ`、`ℝ` 還是一般結構）、有哪些假設、結論的方向。

猜不到名字時，讓 Lean 幫你找。在證明中寫：

- `exact?`：搜尋一條能**直接關閉目前目標**的引理（可能配上手邊的假設）。對上面的目標 `0 ≤ a + b`，它通常會找到 `add_nonneg ha hb`。
- `apply?`：搜尋能套用到目前目標、可能留下子目標的引理。
- `rw?`：搜尋可以用來改寫目前目標的等式。

這些 tactic 在本機執行，可能要等幾秒。它們找到的是**實際存在**的引理，比憑空猜名字可靠。找到之後，把建議的那一行留在檔案中，不要留下 `exact?` 本身。mathlib 的線上文件與搜尋工具，可以從 [Learning Lean 4](https://leanprover-community.github.io/learn.html) 找到入口。

## 自動化不能代替理解

`nlinarith` 能證明 $2xy \le x^2 + y^2$，但如果有人問你「為什麼」，你應該能說「因為 $(x-y)^2 \ge 0$，展開移項」。自動化幫你省下寫細節的力氣，**不能替代**你知道證明的骨架。

這在和 AI 合作時特別重要。AI 很常每一步都試 `simp`、`nlinarith`、`aesop`，碰到一個能過就停。這樣的證明是正確的，但你可能完全不知道它為什麼成立。[第 8 章](../08-project-audit/) 的查核流程會要求你為每個定理寫一段數學說明。

> **查核提示**：AI 給的引理名稱，先 `#check` 確認存在、讀懂它的陳述；用 automation 通過的證明，要能用一句紙上的話說出它為什麼成立。

## 和 AI 一起學

AI 給出的引理名稱有時並不存在，有時存在但陳述和它說的不同（假設不同、方向相反、或只對 `ℕ` 成立而非 `ℝ`）。下面請 AI 推薦引理與工具，再由你逐一驗證。

<AskAI
  task="請 AI 為一個紙上不等式推薦 mathlib 引理與 tactic，再由你用 #check 與 Lean 實際驗證。"
  prompt={"我在學 Lean 4 與 mathlib。我想證明：對所有實數 a、b，若 0 ≤ a 且 0 ≤ b，則 0 ≤ a * b + a。\n請：\n1. 先用中文寫出紙上證明的步驟；\n2. 每一步推薦一個 mathlib 引理或一個 tactic（例如 positivity、linarith），並寫出該引理的完整陳述；\n3. 說明你推薦的 tactic 擅長什麼樣的目標。\n先不要給我完整的 Lean 證明。"}
>

- 對每個引理名稱執行 `#check`。若出現 unknown identifier，先確認 `import`、命名空間與完整名稱；排除這些原因後，再判斷它可能不存在，改用 `exact?` 搜尋。
- 引理存在時，讀它的陳述：型別、假設、結論方向，和 AI 的描述一致嗎？
- 實際用它推進一步，看 Infoview 的目標是否變成你預期的樣子。AI 說「用某某 tactic 可以」時，直接試；失敗了就以 Lean 為準。

</AskAI>

## 練習

### 練習 5.1　翻譯並證明

把「對所有實數 $x$，$x^2 - 2x + 1 \ge 0$」翻成 Lean 並證明。先在紙上想：這個式子可以寫成什麼的平方？然後對照本章的 `uni-two-xy`。

```lean
import Mathlib

theorem my_sq_bound : sorry := by
  sorry
```

<details>
<summary>提示</summary>

陳述是 `∀ x : ℝ, 0 ≤ x ^ 2 - 2 * x + 1`。注意「≥」在 Lean 中通常寫成把小的放左邊的 `≤`。紙上：$x^2 - 2x + 1 = (x - 1)^2 \ge 0$。可以學 `uni_two_xy` 給 `nlinarith` 一個提示項；也可以先用 `ring` 證明恆等式、`rw` 改寫目標，再用 `positivity`。

</details>

<details>
<summary>解答</summary>

```lean
import Mathlib

theorem my_sq_bound : ∀ x : ℝ, 0 ≤ x ^ 2 - 2 * x + 1 := by
  intro x
  nlinarith [sq_nonneg (x - 1)]

-- 另一種寫法：照紙上步驟拆開。
theorem my_sq_bound' : ∀ x : ℝ, 0 ≤ x ^ 2 - 2 * x + 1 := by
  intro x
  have h : x ^ 2 - 2 * x + 1 = (x - 1) ^ 2 := by ring
  rw [h]
  positivity
```

兩個寫法都對應同一個紙上證明：「配方成 $(x-1)^2$，平方非負」。如果你寫成 `∀ x : ℕ, …`，Lean 也會接受，但那是在自然數上的另一個陳述（而且自然數減法會截斷成 0，意思也變了），不是原題。

</details>

## 本章小結

- 形式化時，大部分工作是**找到正確的引理並接上**：猜名字、`#check` 讀陳述、`exact?` 搜尋。
- 先讀目標再選工具：多項式等式用 `ring`，線性不等式用 `linarith`，正性用 `positivity`，化簡用 `simp`，找引理用 `exact?`。
- `ring` 不看假設；需要用假設時，先 `rw` 再計算。
- 自動化通過的證明，你仍要能用一句紙上的話說出理由。
