## 課本上的定義

實數數列 $(a_n)$ 收斂到 $A$，意思是：

> 對每個 $\varepsilon > 0$，存在 $N$，使得對所有 $n \ge N$，都有 $|a_n - A| < \varepsilon$。

量詞順序是「$\forall \varepsilon,\ \exists N,\ \forall n$」：$N$ 可以依賴 $\varepsilon$，但不能依賴 $n$。

在 Lean 中，數列就是一個函數 `u : ℕ → ℝ`，第 n 項寫成 `u n`。這個定義照字面翻成：

```lean
∀ ε > 0, ∃ N, ∀ n ≥ N, |u n - a| < ε
```

符號和課本一一對應，連量詞順序都一樣。這一頁先完全用這個寫法證明，最後才介紹 mathlib 自己的寫法。

## 和的極限：課本的 ε/2 證明

**定理**：若 $a_n \to A$ 且 $b_n \to B$，則 $a_n + b_n \to A + B$。

**證明**：給定 $\varepsilon > 0$。由 $a_n \to A$，對 $\varepsilon/2$ 存在 $N_1$，使得 $n \ge N_1$ 時 $|a_n - A| < \varepsilon/2$。同理存在 $N_2$，使得 $n \ge N_2$ 時 $|b_n - B| < \varepsilon/2$。取 $N = \max(N_1, N_2)$。對 $n \ge N$，由三角不等式，

$$
|(a_n + b_n) - (A + B)| \le |a_n - A| + |b_n - B| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.
$$

證畢。關鍵有三：取 ε/2、取兩個 N 的最大值、三角不等式。下圖是「取最大值」的直覺：

## 紙上證明 ↔ Lean

課程檔案的 `limits-add-eps` 把假設與結論都寫成 ε-N 形式，證明照課本走：

  <Fragment slot="p2">給定 $\varepsilon > 0$。</Fragment>
  <Fragment slot="p3">由 $u_n \to a$，對 $\varepsilon/2$ 取出 $N_1$。（`by linarith` 負責說明 $\varepsilon/2 > 0$。）</Fragment>
  <Fragment slot="p4">同理，對 $\varepsilon/2$ 取出 $N_2$。</Fragment>
  <Fragment slot="p5">取 $N = \max(N_1, N_2)$。</Fragment>
  <Fragment slot="p6">任取 $n \ge N$。</Fragment>
  <Fragment slot="p7">因為 $n \ge N_1$ 且 $n \ge N_2$，兩個估計都成立：$|u_n - a| < \varepsilon/2$、$|v_n - b| < \varepsilon/2$。</Fragment>
  <Fragment slot="p8">把誤差重排成 $(u_n - a) + (v_n - b)$。</Fragment>
  <Fragment slot="p9">三角不等式。</Fragment>
  <Fragment slot="p10">$< \varepsilon/2 + \varepsilon/2 = \varepsilon$。證畢。</Fragment>
</PaperVsLean>

有兩個地方是 Lean 比課本多寫的：

- **第 7 列**：課本直接說「$n \ge N$ 時兩個估計都成立」，省略了 $n \ge \max(N_1, N_2)$ 推得 $n \ge N_1$ 這一步。Lean 要求寫出來，用的是 `le_of_max_le_left` 與 `le_of_max_le_right`。
- **第 8 列**：課本心算的移項，Lean 用 `ring_nf` 說明。

<Term term="calc" short="把一串「= ≤ <」的連續估計，照紙上的樣子一行一行寫出來。">

`calc` 的每一行寫成 `_ 關係 右邊 := 理由`，底線 `_` 代表上一行的右邊。Lean 會檢查每一行的理由，最後把整串關係接起來。這裡是「$=$、$\le$、$<$、$=$」，接起來得到「$<$」。紙上的連續不等式幾乎都可以直接寫成 `calc`。

</Term>

三角不等式在這個 mathlib 版本中叫 `abs_add_le`：`|a + b| ≤ |a| + |b|`。引理名稱在不同版本間有過調整，舊資料可能寫成別的名字。用之前請 `#check abs_add_le` 確認；忘記名字時用 `exact?` 找。

## 課本定義與 mathlib 的 `Tendsto`

mathlib 不用 ε-N 來寫極限，而是寫成 `Tendsto u atTop (𝓝 a)`。白話讀法是「當 n 趨向無窮大時，u n 趨向 a」。看起來陌生，但它和課本定義**等價**，這件事 Lean 可以直接證明：

<LeanCode file="Course/Limits.lean" region="limits-eps-bridge" />

`Metric.tendsto_atTop` 把 `Tendsto` 展開成「$\forall \varepsilon > 0, \exists N, \forall n \ge N$, 距離小於 $\varepsilon$」；`Real.dist_eq` 再說明實數的距離就是 $|x - y|$。所以：

- 拿到一個 `Tendsto` 的假設，可以先用這個等價改寫成 ε-N，再照課本證。
- 上面的 `limits-add-eps` 配上這個等價，就得到 `Tendsto` 版本的和的極限。

<details>
<summary>補充：filter、𝓝 與 atTop 是什麼？為什麼 mathlib 要這樣寫</summary>

`Tendsto` 的完整寫法是 `Filter.Tendsto u Filter.atTop (nhds a)`，`𝓝 a` 是 `nhds a` 的記號。

- `atTop` 描述「n 夠大」：所有「從某個 N 開始的尾段」所形成的 filter。
- `𝓝 a` 描述「夠靠近 a」：a 的所有鄰域所形成的 filter。
- `Tendsto u atTop (𝓝 a)` 說：對 a 的每個鄰域，u 的某個尾段都落在裡面。在度量空間中，鄰域可以取成半徑 ε 的球，這就回到 ε-N 定義。

**filter** 是用來統一各種極限的抽象概念。數列極限、函數在一點的極限、單側極限、趨向無窮的極限，都是同一個 `Tendsto` 搭配不同的 filter。好處是「和的極限是極限的和」這類引理只要證一次，就能用在所有情況。代價是初學時讀起來不像課本。

`Metric.tendsto_atTop` 的確切形式是：

```text
Tendsto u atTop (𝓝 a) ↔ ∀ ε > 0, ∃ N, ∀ n ≥ N, dist (u n) a < ε
```

可以用 `#check Metric.tendsto_atTop` 在你的 mathlib 版本中確認。

</details>

## mathlib 已有：一行的版本

因為 mathlib 把「和的極限」寫成一般的引理 `Filter.Tendsto.add`，`Tendsto` 版本的定理只要一行：

<LeanCode file="Course/Limits.lean" region="limits-add" />

`hu.add hv` 的意思是「把 `Tendsto.add` 套用到 `hu` 與 `hv`」。對照時請確認：

- 序列型別是 `ℕ → ℝ`，對應課本的實數數列。
- 結論的極限是 `a + b`，結論中的序列 `fun n => u n + v n` 就是逐項相加。

這一行完全正確，但看不到 ε/2 的論證。兩種寫法各有用途：**要學證明方法**，從定義出發寫一次；**要在更大的證明裡用到這個事實**，直接用 mathlib 的引理。

## 查核要點

- **量詞順序**：$\exists N$ 必須在 $\forall n$ 之前。例如有人把收斂寫成 `∀ ε > 0, ∀ n, ∃ N, n ≥ N → |a n - A| < ε`。這時 N 可以依賴 n：對任意 n，取 N 大於 n，條件 `n ≥ N` 就是假的，蘊含自動成立。所以這個「定義」對任何數列都成立，沒有任何內容。
- **嚴格不等號**：定義中 $\varepsilon > 0$ 是嚴格的。誤寫成 $\varepsilon \ge 0$ 會讓定義無法滿足（取 $\varepsilon = 0$）。結論寫成 $\le \varepsilon$ 恰好等價，但最好和課本一致。
- **索引型別**：數列是 `ℕ → ℝ`。寫成 `ℤ → ℝ` 時 `atTop` 仍有意義，但已經不是課本上的數列。
- **公理**：實分析的證明幾乎一定會用到 `Classical.choice` 等標準公理，這是正常的。

> **查核提示**：Lean 通過只代表「你寫的陳述」成立。極限的翻譯最容易錯在量詞順序：請逐字確認是「∀ ε，∃ N，∀ n ≥ N」，而且 N 沒有偷偷依賴 n。

## 練習

### 練習 A1.1　翻譯並證明：常數倍

把「若 $a_n \to A$，則對任意實數 $c$，$c \cdot a_n \to c \cdot A$」翻譯成 ε-N 形式的 Lean 陳述並證明。先寫出陳述，檢查量詞順序與假設，再動手。

```lean
import Mathlib

example (u : ℕ → ℝ) (a c : ℝ) : sorry := by
  sorry
```

<details>
<summary>提示一：陳述與紙上證明</summary>

假設與結論都寫成 `∀ ε > 0, ∃ N, ∀ n ≥ N, |… - …| < ε`。紙上證明的關鍵是 $|c u_n - c a| = |c| \cdot |u_n - a|$。課本常取 $\varepsilon / |c|$，但 $c = 0$ 時要另外處理。有一個避開分情況的技巧：改取 $\varepsilon / (|c| + 1)$，因為 $|c| + 1 > 0$ 永遠成立。

</details>

<details>
<summary>提示二：Lean 中的步驟</summary>

結構和本頁的 `limits-add-eps` 相同，只是只有一個 N。`|c * u n - c * a|` 可以用 `rw [← mul_sub, abs_mul]` 改寫成 `|c| * |u n - a|`。估計的部分用 `calc`：先 $\le |c| \cdot \frac{\varepsilon}{|c| + 1}$，再 $< (|c| + 1) \cdot \frac{\varepsilon}{|c| + 1}$，最後 $= \varepsilon$。各行可以試試 `gcongr`、`field_simp`；正數條件用 `positivity`。

</details>

<details>
<summary>解答</summary>

```lean
import Mathlib

example (u : ℕ → ℝ) (a c : ℝ) (hu : ∀ ε > 0, ∃ N, ∀ n ≥ N, |u n - a| < ε) :
    ∀ ε > 0, ∃ N, ∀ n ≥ N, |c * u n - c * a| < ε := by
  intro ε hε
  have hc : 0 < |c| + 1 := by positivity
  obtain ⟨N, hN⟩ := hu (ε / (|c| + 1)) (by positivity)
  refine ⟨N, ?_⟩
  intro n hn
  have h := hN n hn
  calc |c * u n - c * a| = |c| * |u n - a| := by rw [← mul_sub, abs_mul]
    _ ≤ |c| * (ε / (|c| + 1)) := by gcongr
    _ < (|c| + 1) * (ε / (|c| + 1)) := by gcongr; linarith
    _ = ε := by field_simp
```

`gcongr` 的意思是「兩邊長得一樣，只比較不同的那一個因子」：

- 第二行：兩邊都是 $|c| \cdot (\ldots)$，`gcongr` 只比較括號內的因子，要用到 $|u_n - a| < \varepsilon / (|c| + 1)$（即 `h`）。因為 $|c|$ 可能是 0，乘上去之後只能保證 `≤`，不能保證 `<`。
- 第三行：兩邊都是 $(\ldots) \cdot \frac{\varepsilon}{|c| + 1}$，`gcongr` 只比較前面的因子，留下子目標 $|c| < |c| + 1$，由 `linarith` 解決。這次乘上的 $\frac{\varepsilon}{|c|+1}$ 一定是正的，所以嚴格不等式 `<` 能保留下來。

若改用 mathlib 的 `Tendsto` 寫法，這個定理也是一行：`Filter.Tendsto.const_mul`。

```lean
example (u : ℕ → ℝ) (a c : ℝ) (hu : Filter.Tendsto u Filter.atTop (nhds a)) :
    Filter.Tendsto (fun n => c * u n) Filter.atTop (nhds (c * a)) :=
  hu.const_mul c
```

</details>

## 本單元小結

- 課本的 ε-N 定義在 Lean 中照字面寫成 `∀ ε > 0, ∃ N, ∀ n ≥ N, |u n - a| < ε`，量詞順序完全一樣。
- 「和的極限」的 ε/2 證明，在 Lean 中是 `intro ε`、兩次 `obtain` 取出 N₁ 與 N₂、`max N₁ N₂`、再用 `calc` 寫三角不等式。
- mathlib 用 `Tendsto u atTop (𝓝 a)` 寫極限，它和 ε-N 定義等價（`limits-eps-bridge`）；mathlib 已有的 `Tendsto.add` 讓整個定理只要一行。
- 查核極限陳述時，先看量詞順序，再看嚴格不等號與索引型別。AI 給的引理名稱，用 `#check` 確認。
