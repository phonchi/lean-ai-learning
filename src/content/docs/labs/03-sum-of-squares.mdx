## 數學內容

設 x₁, x₂, ..., xₙ 是實數（可以重複，順序有意義）。考慮平方和 S = x₁² + x₂² + ... + xₙ²。

**命題一**：S ≥ 0。理由：每一項平方都非負，非負數之和非負。

**命題二**：S = 0 若且唯若每個 xᵢ = 0。

- 「若」的方向：每項都是 0，平方和當然是 0。
- 「唯若」的方向：假設 S = 0。對任一個 xⱼ，有 0 ≤ xⱼ² ≤ S = 0，因為其他各項都非負。所以 xⱼ² = 0，進而 xⱼ = 0。

命題二的關鍵是一個一般原則：**一群非負數的和為零，若且唯若每一個都是零**。這個原則對實數成立，因為實數有序，非負數相加不會「抵銷」。注意命題二的證明**用到**命題一：要知道「其他各項之和」非負。

在本次實戰中，**命題一已經提供**，是你可以直接使用的輔助引理；**命題二才是待完成的練習**。

## Lean 中的寫法：定義與已提供的引理

在 Lean 中，用 `List ℝ` 表示這串實數。課程專案在 `Course/Squares.lean` 中定義了平方和 `Course.squareSum`：先用 `List.map` 把每個元素平方，再用 `List.sum` 加總。同一個區段也證明了命題一 `Course.squares_nonneg`：

<LeanCode file="Course/Squares.lean" region="squares-nonneg" />

先逐行讀懂它：

- **定義**：`squareSum xs` 先把列表每個元素平方（`List.map`），再全部加起來（`List.sum`），正是「每個元素的平方之和」。空列表平方後還是空列表，空列表的和是 0，所以 `squareSum [] = 0`，和數學上「空和為 0」的約定一致。
- **基底**：`nil` 情況的目標是 `0 ≤ squareSum []`，`simp [squareSum]` 展開定義後就是 `0 ≤ 0`。
- **歸納步驟**：`add_nonneg (sq_nonneg x) ih` 對應的數學句子是「$x^2 \ge 0$，而由歸納假設其餘各項的平方和也 $\ge 0$，兩個非負數相加仍非負」。

只留一題給你想：`cons` 情況中，`change` 那一行把目標改寫成什麼？為什麼這樣改寫是合法的？（提示：想想 `map` 與 `sum` 在 `x :: xs` 上依定義展開的結果。`change` 只接受和原目標「依定義相同」的改寫，否則 Lean 會報錯。）

## 第一步：翻譯檢查與邊界情況（你自己做）

### 為什麼用 `List` 而不是 `Finset`

`Finset` 是**集合**，同一個元素只出現一次；`List` 保留重複與順序。原題說的是「一串實數」，例如 1, 1, −1 是三個數，平方和是 3。如果用 `Finset`，重複的 1 只會算一次，平方和只剩 2。所以 `List` 才忠實於原題。

### 空列表

當 `xs` 是空列表 `[]` 時：

- 平方和是空和，等於 0。命題一成立。
- 「每個元素為零」是 `∀ x ∈ [], x = 0`，由於空列表沒有元素，這個敘述**空虛地為真**（vacuously true）。
- 所以命題二在空列表時是「0 = 0 若且唯若 真」，成立。

這和數學上的約定一致。請確認你同意這一點，再繼續。這也是歸納法的基底情況。

### 重複值與零

- `[0, 0, 0]`：平方和 0，所有元素為 0，命題二兩邊皆真。
- `[1, -1]`：平方和 2，不是所有元素為 0，兩邊皆假。注意 1 + (−1) = 0，但平方和不是 0，這正是「平方」的作用。
- `[0, 2]`：平方和 4，兩邊皆假。

這些都只是檢查，不是證明。

## 提示與解答

<details>
<summary>命題二：基底情況的提示</summary>

空列表時，兩邊分別是「空和等於 0」與「空列表上的全稱敘述」。把 `Course.squareSum` 的定義交給 `simp` 展開即可，例如 `simp [Course.squareSum]`。

</details>

<details>
<summary>命題二：歸納步驟的提示</summary>

先讓目標中出現 `x ^ 2 + Course.squareSum xs`：可以用 `change`，或用 `have` 寫出這個等式並以 `rfl` 證明，再 `rw`。右邊的「對 `x :: xs` 的每個元素」可以用 `List.forall_mem_cons` 拆成「x 是 0 且對 `xs` 的每個元素」。接著 `constructor` 分兩個方向。

</details>

<details>
<summary>命題二：「唯若」方向的提示</summary>

手上有 `x ^ 2 + Course.squareSum xs = 0`、`0 ≤ x ^ 2`（`sq_nonneg x`）與 `0 ≤ Course.squareSum xs`（`Course.squares_nonneg xs`）。這是兩個非負量相加為零，`linarith` 可以分別推出 `x ^ 2 = 0` 與 `Course.squareSum xs = 0`。前者用 mathlib 的 `sq_eq_zero_iff` 得到 `x = 0`，後者交給歸納假設。

</details>

<details>
<summary>命題二：「若」方向的提示</summary>

已知 `x = 0` 且 `xs` 的每個元素為 0。用歸納假設的反方向得到 `Course.squareSum xs = 0`，把兩者代入目標，剩下 `0 ^ 2 + 0 = 0`，交給 `norm_num`。

</details>

<details>
<summary>選做（命題一）的提示</summary>

對 `xs` 歸納。`cons` 情況中，目標可以改寫成 `0 ≤ x ^ 2 + Course.squareSum xs`，用 `add_nonneg` 結合 `sq_nonneg x` 與歸納假設。

</details>

<details>
<summary>參考證明（完成後再看）</summary>

課程的參考證明如下。它在「唯若」方向使用 `nlinarith`，與上面提示的路線略有不同。agent 給出的證明可能與參考完全不同；只要通過查核、你能解釋，而且沒有引用這個參考定理，就是可以接受的。

<LeanCode file="Course/Squares.lean" region="squares-zero" />

讀這段證明時，要先看懂兩件事：

- **`ih` 是一個「若且唯若」**：`squareSum xs = 0 ↔ ∀ y ∈ xs, y = 0`。`ih.mp` 是它的正方向（和為 0 ⇒ 每項為 0），`ih.mpr` 是反方向（每項為 0 ⇒ 和為 0）。「唯若」方向用 `ih.mp`，「若」方向用 `ih.mpr`。
- **「列表 `x :: xs` 的每一項都是 0」可以拆成兩半**：`x = 0`，而且 `xs` 的每一項都是 0。`simpa only [List.mem_cons, forall_eq_or_imp]` 就是在做這個改寫，接著用 `And.intro hx (ih.mp ht)` 交出這兩半。

</details>
